# Banco Digital   

Este projeto simula um banco digital, permitindo operações básicas como depósito, transferência e listagem de clientes

## Estrutura do Projeto  
- `Banco.java` → Gerencia as contas e clientes
- `Conta.java` → Classe base para contas bancárias  
- `ContaCorrente.java` e `ContaPoupanca.java` → Tipos específicos de conta  
- `Cliente.java` → Representa o titular da conta  
- `Main.java` → Executa e testa as funcionalidades
